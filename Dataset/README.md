# Dataset

This folder is a publication-boundary placeholder. No dataset files are committed here: the raw and processed clock drawings, master evaluation workbook, and source manifest remain outside GitHub.

The project began with 400 original image records; the documented evaluated release contains 363 reviewed records. See the [Dataset Card](../docs/Dataset_Card.md) for composition and lineage, and [Source Provenance](../docs/References/Source_Provenance.md) for the team-reported NHATS Round 14 source and the fact that local files have not been independently matched to that release.

NHATS access is individual and governed by the [NHATS Conditions of Use](https://www.nhats.org/conditions-of-use). This folder contains no files other than this explanatory README.
