# Controlled data

This folder marks materials intentionally excluded from GitHub: original and processed clock images, dataset archives, row-level labels, split manifests, predictions, conflict reviews, record dispositions, and per-image hashes.

These files remain in controlled storage and are not linked from this repository. [NHATS Conditions of Use](https://www.nhats.org/conditions-of-use) require individual access and restrict transfer and uploads to covered public AI services. This folder contains no files other than this explanatory README.
